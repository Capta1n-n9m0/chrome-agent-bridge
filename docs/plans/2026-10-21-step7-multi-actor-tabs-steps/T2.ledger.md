## Design (for the builder; decided by the step agent unless ruled otherwise)

- New pure modules: `handles.ts` (HandleTable: idempotent `mint`, monotonic `T<n>`, `resolve` →
  live/gone/unknown, `handleOf`, `replace`, `remove` with lastUrl/lastTitle, `prune(now)` 1 h / 1 000,
  url/title cache, `live()`), `leases.ts` (LeaseTable keyed by handle: grant/release/releaseAll/ownerOf/
  check), `lock.ts` (VisibilityLock: FIFO, per-acquisition idempotent release, deadline → LOCK_TIMEOUT
  {holder: name}, `releaseAllOf(clientId)`, injected clock), `methods.ts` (the one table, #39),
  `intercept.ts` (the tab layer).
- Table: tab-carrying + lease-checked = navigate snapshot screenshot click type scroll hover
  selectOption pressKey back forward waitFor evaluate networkClear focusTab selectTab; intercepted +
  lease-checked = closeTab (only there, V8); intercepted no tab = newTab listTabs; free forwarded =
  networkRequests downloadStart downloadChunk downloadEnd; daemon-handled = daemon.* tabs.claim
  tabs.release; lock = screenshot when `mode !== "cdp" && !fullPage`, focusTab (selectTab: Escalation 1.3);
  unlisted: free if no `tab`, else resolved + lease-checked.
- Order: Step 6 validation → daemon.* → tabs.claim/release → NOT_CONNECTED → VERSION (no-proto extension,
  tab-carrying) → resolve (handle | legacy human's tab via `listTabs` `current:true` | closeTab/selectTab
  `id`) → TAB_UNKNOWN/TAB_GONE → lease check (TAB_HELD {owner: name, since}) → lock (deadline) → forward
  with `tabId`, `tab` stripped, wait `deadline − now + 5000` → release once.
- Network: handle → tabId; `"all"` → `scope:"all"`; `"active"`/absent → human's tab; number → BAD_PARAMS;
  `networkRequests {id}` → no scope; `networkClear {tab:"all"}` → TAB_HELD if a foreign-held tab has
  `total > 0`; daemon annotates entries with `tab` (F12).
- newTab: forward, mint + grant "opened" to caller, result `{id, tab}`; opener grants deferred while a
  newTab is in flight (F20), so no wrong `leaseGranted`.
- Events (guards #50): tabCreated → mint, opener rule → leaseGranted; tabRemoved → gone + tabGone to
  holder + lease dropped; tabReplaced → remap. Still counted.
- Proto:2 extension hello → resync from `listTabs` (F15); v1 → none. Disconnect → releaseAll +
  releaseAllOf. Status adds `tabs`, `lock`. One legacy log line per client, no URL (via a `log` option
  wired in `main.ts`).
