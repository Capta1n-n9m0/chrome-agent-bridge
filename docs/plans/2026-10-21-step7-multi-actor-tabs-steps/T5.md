## 6. Proposed decisions (for the session agent / the user)
- **2026-10-22 · SCREEN-1/3/5 and RESOLVER-1 are re-run with a corrected, newly pre-registered check.**
  The image check is a hue test on a probe off the label (e.g. (1900,20): red > 180, green < 60, blue >
  180 for magenta), and RESOLVER-1's foreground is judged by window handle. *Why:* the as-written checks
  could not pass a correct image (label glyph at (20,20); a colour-managed capture reads `#dd00fa`). The
  wave verifier notes that this is a new rule, so it must be pre-registered and ruled on before any
  re-run. *Instead of:* re-reading these runs as PASS, which is forbidden.
- **2026-10-22 · NET-1 uses a cache-proof URL.** `…?t5=net1` (or a check of `from cache: no`). *Why:*
  the plain URL came from Chrome's cache (W1's 12 914-byte copy). T5.3 stays not met until the user rules.
- **2026-10-22 · `mode:"cdp"` refuses a hidden or minimized tab, or the extension bounds it.** *Why:*
  SCREEN-2 and SCREEN-4 hang to the daemon's TIMEOUT (35 s / 25 s), with the banner up. For Step 8, or a
  Step 7 follow-up.
- **2026-10-22 · A capture that times out still restores the previous tab.** *Why:* SCREEN-5's first
  attempt left the target active ≥ 49 s (the restore runs only after `captureVisibleTab` settles). An
  extension change, so outside a wave.
- **2026-10-22 · Step 8's policy: trusted input needs the tab in front.** *Why:* BG-1/BG-2 are silent
  no-ops in the background (`ok` in 5–10 ms) and work after `focusTab`. The focus-emulation retry needs a CDP
  pass-through or a `focusEmulation` option (#61).
- **2026-10-22 · The SCREEN-1 flash (~1.5 s) is investigated.** *Why:* 1.5 s ≈ the 1 s activation wait at
  its limit + 50 ms + the capture, which suggests `onActivated` does not end the wait (unconfirmed).
  Lowering a wait without a measurement remains forbidden.
- **2026-10-22 · `leaseGranted.url` is filled after `onUpdated`, or documented as possibly empty.** *Why:*
  LEASE-3 got `""` for a link popup (F33).
- **#45 revisit:** LEASE-6 shows a discard **does** replace the tab id on Chrome 156 (the trigger is met);
  the spec §3 rationale stands; Stage 0 F7's premise was wrong.
