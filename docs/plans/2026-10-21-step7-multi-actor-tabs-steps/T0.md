## Proposed decisions

- **2026-10-22 · No `isScreenshotMode` guard in shared.**
  - Decided: no guard is added.
  - Why: T2 needs only `params.mode === "cdp"` to skip the lock. Anything else is treated as `switch`, which is the default and takes the lock, so it is the conservative side.
  - Instead of: exporting `isScreenshotMode`.
  - Revisit if: an unknown `mode` must be rejected with `BAD_PARAMS`.
- **2026-10-22 · The Step 7 event guards are strict on field types and lenient on extra fields.**
  - Decided:
    - required fields must be present and correctly typed;
    - tab ids use `Number.isInteger`, with no lower bound;
    - an optional field that is absent or `undefined` passes;
    - `null` or a wrong type rejects the whole frame;
    - unknown fields are accepted.
  - Why: the sender is our own extension or daemon, so strictness surfaces bugs. `undefined` disappears in JSON, so treating it as absent keeps in-process tests and the wire in agreement (verifier F2). Accepting extra fields matches `isHello`.
  - Instead of: treating `null` as absent; rejecting `undefined`; requiring `tabId > 0`.
  - Revisit if: T1 needs to send `null`, or a `-1` tab id reaches the daemon.
- **2026-10-22 · The content-script `{__bridgeError}` shape stays out of shared (#38).**
  - Why: it never crosses a package boundary; it goes from the content script to the service worker, both inside `extension/`.
  - Instead of: a shared type.
  - Revisit if: another package needs to read it.
- **2026-10-22 · v2 peers do not yet require `code` (the D0 revisit). For user review.**
  - Decided: `WireError.code` stays optional, and `fromWire` still maps a missing, non-string or empty code to `INTERNAL`.
  - Why: no pre-stated rule tightens it, and under the conservative rule existing behaviour stays identical. A stale v1 extension's `{message}` must still arrive (Stage 0 F22), and #42 refuses such an extension for tab calls anyway.
  - Instead of: rejecting a v2 error without `code`.
  - Revisit if: Step 8 removes the v1 fallback and the `activeTab()` fallback.
