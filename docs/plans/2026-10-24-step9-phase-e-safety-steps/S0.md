## 5. Proposed decisions

### 2026-10-24 · The `listTabs` row types in `shared/` make title and url optional (S0)
**Decided:** `protocol.ts` exports two types:
- `ExtensionListTabsRow`: the extension's row;
- `ListTabsRow extends ExtensionListTabsRow`: adds the daemon's `tab` and `owner?`.

In both, `title?` and `url?` are optional, and `hidden?: HiddenReason` marks a row that withholds them.
Types only: no reader uses them yet.
**Why:** #134 drops title and url from a hidden row, so a required field would make the type lie.
**Instead of:**
- one type with an optional `tab?`;
- required fields filled with `""` (contradicts #134).

**Revisit if:** S2a or S3 needs the two collapsed.
**By:** Claude (proposed)

### 2026-10-24 · `isSafetyState` requires a non-negative safe integer and a non-array object (S0)
**Decided:**
- `blockedCount` must pass `Number.isSafeInteger` and be ≥ 0;

**Why:** a count is never fractional, negative or huge; an array is never a state.
**Instead of:** `Number.isInteger`.
**Revisit if:** never expected.
**By:** Claude (proposed)
