## 5. Proposed decisions

The builder's five, in `S2-builder.md` §5 (format §5): covered methods are `navigate`, `back`, `forward` (tab) and
`downloadStart` (download), `newTab` not (#295, #296 item 8); a list change between a call's creation (or `mark()`)
and its install refuses that install (the keeper holds no list copy); `rebuild(null)` changes no rule and refuses live
replies but does not unsync (the gate refuses new calls on an unreadable state anyway); unsynced ends only on a good
rebuild, a failed start-up clear is retried by the next install or rebuild; ids from one growing counter, a rejected
removal leaves orphans retried by every later update (since the fix round, the install's update too).

Verifier's for user review (`S2-verifier.md`, V3): after a failed rebuild, covered calls stay refused until the next
block-list edit or a worker restart, even with no live call and Chrome healthy — 0.5's letter, harsher than its intent;
proposed: become synced again once the last live call is released (or the next install retries the rebuild). Not
built; for the session agent.
