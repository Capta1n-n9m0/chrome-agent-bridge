## Findings (incl. gotcha candidates)

1. **Gotcha candidate:** Windows PowerShell 5.1 drops an empty argument passed through `powershell -File`:
   `-ArgLine ''` arrived with no value → `Missing an argument for parameter 'ArgLine'`, exit 1 (RET-1, Return 4). Omit
   an empty parameter and let its default apply.
2. **Gotcha candidate:** headless `claude -p` actors call `ToolSearch` first (this Claude Code defers MCP tools) unless
   started with `ENABLE_TOOL_SEARCH=false`; a check on "exactly [tool]" then fails (MCPF-1, CAP-1; wave fixer 2's
   offline dummy-MCP check).
3. **Gotcha candidate:** session restore adds Chrome windows after a relaunch, so "exactly one new window" is not a
   safe test; wait for a stable window set and pick only a window carrying a unique title marker (#223; Return 5).
4. **Gotcha candidate:** a Chrome-owned topmost, no-activate popup (`Chrome_WidgetWin_1`, 223×25 px at the window's top
   right) owned by the options window appears after a switch is toggled through that page (Return 3, again in attempt
   4) — the Run 14 occluder's likely identity.
5. **Gotcha candidate:** `printf` in Git Bash turns `\a` in a Windows path (the `\a` of `C:\Users\a…`) into a control
   character (BEL); pass Windows paths as a `%s` argument or with forward slashes (met during S7, per the step agent).
6. **Gotcha candidate (live verifier 1):** a differential capture row can be confounded by the first call's cost or
   the 2/s capture-slot spacing (SW-1R trial 1: front 870 ms vs 287/218) — a warm-up trial belongs in the row.
7. **Gotcha candidate (live verifier 2, 3):** a read-back helper that throws after launching its own window leaves it
   open; overwriting a scan's input on resume makes an earlier attempt's PASS unverifiable — archive per attempt.
8. **Measured:** `saveTo` live: 1 MiB, 4 MiB, 2 MiB with surrogates, JSON, a 418 754-byte export and 64 MiB saved
   whole by sha256 through the SDK and the MCP; the 64 MiB read-out took 4.3 s and raised the extension renderer's
   private memory by ~212 MiB (record); the store's TTL, hold, close, disarm, JavaScript-off and block refusals as built.
9. **Measured:** with the opener behind, Chrome names another tab as the popup's opener, so no `leaseGranted` (R15-POP-2
   (b)) — Run 14's R14-POP-1 FAIL is explained, not a daemon defect (#211's Revisit-if not met).
10. **Measured:** a killed and relaunched Chrome retired 3 held handles (`extension session changed: 3 handles retired`),
    sent `tabGone` with the last fixture URL, and the old Tab answered `TAB_GONE`; the safety state survived the kill
    (RET-1R; #126's live row).
11. **Measured:** bb-login's new wait (0.9) exits 0 on the delayed redirect where the old one exits 4, and ends at the
    90 s bound on a stuck or foreign page; the real pp1 login took one press.
