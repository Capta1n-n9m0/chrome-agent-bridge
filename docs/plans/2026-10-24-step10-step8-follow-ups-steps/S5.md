## Proposed decisions

- **2026-10-25 · bb-login's exit 0 needs a document, ≥ 1 control and two clean scans** — Decided: exit 0 only on the
  Blackboard host with two consecutive scans after the last address change, each a document with ≥ 1 Edit/Button
  control and no sign-in button, address unchanged 4 s. Why: Chrome builds the accessibility tree lazily, so an empty
  scan would read as "no sign-in control". Instead of: one scan with 0 matches; a `Get-StableScan` (can run past the
  bound, F10). Revisit if: a real logged-in Blackboard page shows 0 controls (the script would exit 4 at the bound).
- **2026-10-25 · No scan starts in the last max(5 s, slowest scan) before the bound** — Decided as above, plus a
  deadline check after each scan (exit 4 past it). Why: S5.1's ≤ 95 s from the press with a synchronous scan. Instead
  of: a hard cap via a separate runspace (complex), or the plain poll (23.1 s at `-WaitSec 20` on a heavy page).
  Revisit if: the first G10-3 run records a single real-page scan over 5 s.
- **2026-10-25 · The poll reads the host without the "Not secure" chip** — after the press nothing is pressed, so the
  https veto has nothing to veto. Revisit if: an exit-0 decision ever needs the scheme.
- **2026-10-25 · A vanished own window ends the wait with exit 4 at once** — Instead of: waiting to the bound and
  printing "left open" for a window that no longer exists (the old behaviour). Exit-code meaning unchanged.
- **2026-10-25 · Fixture counters carry a fresh `?t=`** — Chrome answered a repeated plain URL from its cache.

## Findings

1. **A real Blackboard page's scan time is unmeasured** (G10-3). Worst seen on stand-ins 18 ms; synthetic heavy pages
   3.8–4.2 s. The first real run (S7's BBL-1 is dry-run only; a real run waits for G10-3) should record the slowest
   scan the script prints.
2. **The old script never ended in exit 1 on a closed window** — the verifier's round-1 claim was wrong (the fixer
   measured exit 4 at the bound with a false "left open"); the verifier accepted the correction.
3. Gotcha candidate for S8 / CLAUDE.md: **PowerShell variable names are case-insensitive, so a local `$h` in a
   function shadows a script-level `$H` through dynamic scope** (builder, measured: `Close-Own` cast "127.0.0.1" to
   IntPtr, exit 1).
