## New CLAUDE.md gotcha candidates

1. (Predecessor) **`String(fn)` page code breaks under tsx** (keepNames `__name`). Recipes ship page code as
   literal strings (S6 builder; the pre-run verifier reproduced it in node:vm).
2. (Predecessor) **PowerShell 5.1's built-in alias `R` (`Invoke-History`) shadows a function named `R`** (Run 12
   Part 1 set-up).
3. (Predecessor) **Windows PowerShell 5.1 strips embedded `"` from a native command's arguments.** Send JSON-bearing
   actor prompts from Git Bash (Run 12 driver).
4. **`chrome://quit` closes every tab before the extension's session changes.** A leased handle is therefore retired
   by `tabGone` at the quit, and the restart's `extension session changed` retires 0. Measured twice: Run 12 Part 2
   SM-1, and Part 3 SM-1 (`tabGone` +1539 ms after `$Q`, `0 handles retired`).

   +20 ms, the human tab hidden 1331 ms, call 1344 ms (Run 12 Part 2 REP-0, with blue/magenta controls).
6. **An MCP failure report's PNG did not reach a `claude -p` actor as an image while the result was `isError`.**
   Measured in Part 2 REP-1, and found by the S6b probe. Fixed by #100 (a non-error result when an image is
   present); Part 3 REP-1 measured 1 image part.
7. **Default-mode captures shift cyan's red channel past the hue rule; blue reads true** (`#3300f8`, Run 9 / REP-0
   control A). Use blue or magenta for colour controls (S6 verifier r2, from Run 9's readings).
8. **A full-window OS frame includes Chrome's own UI** (the user's bookmark bar). Judge frames by numbers or crop to
   the viewport (Run 12 Part 2, LOC-1).

   (`~/.claude/projects/<proj>/<session>/tool-results/…png`), and prints an `[Image: source: …]` part. Measured in
   S6b (`S6b.md` §6 finding 2) and seen again in Run 12 Part 3 REP-1. A failure-report PNG therefore leaves a
   second copy outside `~/.chrome-agent-bridge/failures/`.

    nothing.** Measured: the sheet's command 0, the literal path with `-Filter` 1, and `…\*.png` without `-Filter`
