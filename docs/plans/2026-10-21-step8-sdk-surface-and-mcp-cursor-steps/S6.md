## New CLAUDE.md gotcha candidates

- **`String(fn)` page code breaks under tsx**: tsx 4.23.15's keepNames inserts calls to a module-level
  `__name` helper, so a function shipped as `String(fn)` fails in the page with `ReferenceError: __name is
  not defined`; vitest does not add it, so tests pass (builder found; pre-run verifier reproduced in
  node:vm). Recipes ship page code as literal source strings. The extension bundle (esbuild) is unaffected.
- **PowerShell 5.1's built-in alias `R` (`Invoke-History`) shadows a function named `R`** in a dot-sourced
  block (Run 12 set-up, `S6-run-record.md`).
- **Windows PowerShell 5.1 strips embedded `"` from a native command's arguments**, so JSON-bearing actor
  prompts were sent from Git Bash (Run 12 driver, `S6-run-record.md`).
