## 6. Proposed decisions (from the builder; for the session agent)

### 2026-10-25 · S1's marker is a module-private WeakSet
**Decided:** `markOwnRefusal(err)` records membership in a `WeakSet` that is private to `debugger-errors.ts`. A copy of
a marked error is not marked, and only an own coded `BridgeError` passes through.
**Why:** a marker carried by the error's shape could be forged or copied onto page errors.
**Instead of:** a property or a subclass.
**Revisit if:** errors are cloned across a boundary before `describeDebuggerError`.
**By:** Claude (proposed)

### 2026-10-25 · S1 marks the value refusals and the cap; the save leg's INTERNAL failures keep the prefix
**Decided:** the marked set is the value refusals in `save.ts` (including the stringify `PAGE_ERROR`) and the
in-session size cap. The save leg's `INTERNAL` failures and its transfer timeout keep `[chrome.debugger] `.
**Why:** #246 names "the `saveTo` refusals", meaning SAVE-REFUSE's set (#207, #218). The `INTERNAL` failures are
breakdowns, not refusals. Outside the session the cap was already unprefixed.
**Instead of:** marking every own error that `save.ts` throws.
**Revisit if:** the user wants the `INTERNAL` failures or the timeouts unprefixed.
**By:** Claude (proposed; wire message text, **for user review**)

### 2026-10-25 · The wording of `kind` in `saveTo`'s description
**Decided:** the description now reads `… answer only the path, size, kind ("string" for a string saved as is, "json"
for anything else) and sha256 …`.
**Why:** it names both values that `evaluateSaveStart` returns (#218).
**Instead of:** a bare "kind".
**Revisit if:** a third `kind` appears.
