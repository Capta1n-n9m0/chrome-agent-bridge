**The minimal change outside the lane** (the verifier measured it):

  (returns `[tabTarget]`);

**Options:**
- **(i) Recommended:** widen S2's lane to those two `safety-call.ts` labels plus a **stub** registration in `sw.ts`
  that throws a fixed `INTERNAL "not built"`. S3 replaces the stub. The table entry, the `safetyDecision` branch that
  calls `uploadRefusal`, and the S2.2/S2.5 gate rows then all land in S2, through `CallSafety` with a tab read

    folder list is empty, because the gate answers `UPLOAD_REFUSED` first. It keeps S3's handler work separate.
- **(ii)** Move the table entry and its rows to S3, together with the real handler. This leaves S2.2 and the gate part
  of S2.5 to be closed in S3.
- **Not acceptable:** loosening the router-scan test. It is a protective check (§2).
