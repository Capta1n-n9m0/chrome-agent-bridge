## 2. The one targeted web lookup (WebFetch), source recorded

Returned (the fetch tool's summary; its quotes are capped at 125 characters):
  - DOMHandler::DOMHandler(bool allow_file_access) stores it in allow_file_access_ ; SetRenderer only sets host_.
  - SetFileInputFiles: if allow_file_access_ is false it returns Response::ServerError("Not allowed");
    if host_ is set it calls ChildProcessSecurityPolicyImpl::GetInstance()->GrantReadFile(process id, FilePath::FromUTF8Unsafe(file))
    for each file, then returns Response::FallThrough() (the renderer's DOM agent does the rest).
  - "Not allowed" is the only error string on the page (also GetFileInfo).
  - The page does NOT show where the constructor's flag comes from for an extension client (not fetched: one lookup only).
