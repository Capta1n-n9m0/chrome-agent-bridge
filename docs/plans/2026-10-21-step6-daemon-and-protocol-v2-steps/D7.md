## 5. Proposed decisions

### 2026-10-22 · setup.md documents stopping the daemon by killing its process, with no stop script
**Decided:**
- `setup.md` documents the idle exit and the OS commands that stop the process:
  - Windows: `Get-NetTCPConnection -LocalPort 9234 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess }`.
  - Linux/macOS: `pkill -f daemon/dist/index.js`, plus a note for `BRIDGE_DAEMON` paths.
- It warns that an open MCP starts a new daemon 5 s later.
- It offers no `daemon.shutdown` recipe as a stop command.

**Why:** No stop command exists. `daemon.shutdown` closes clients with 4002, which SDK clients
treat as "reconnect", and a reconnect may spawn a new daemon.
**Instead of:** a tsx snippet that calls `daemon.shutdown`, which would be untested and misleading.
**Revisit if:** Step 8 adds a stop command to the SDK, or D6's runner ships a helper worth naming.
**By:** Claude (proposed)
